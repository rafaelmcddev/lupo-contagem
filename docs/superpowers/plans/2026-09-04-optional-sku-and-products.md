# Optional SKU Requirement + Products Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make SKU linking configurable (a per-counting-frozen `require_sku` setting, default on = current behavior) instead of always mandatory, and add a **Produtos** catalog screen (barcode + SKU + product name: add/edit/remove one at a time, or bulk via CSV import) so staff can pre-register products before a delivery instead of only linking a SKU inline while scanning.

**Architecture:** Extends the existing "Lupo Contagem" Next.js 14 App Router app (already built and deployed per `docs/superpowers/plans/2026-09-03-lupo-contagem.md`). Reuses the existing `skus` table (adds a nullable `name` column) as the Products catalog's backing store — the inline scan-time SKU prompt and the new Produtos screen both read/write the same table, just through different entry points. `countings` gains a frozen `require_sku_used` boolean column, mirroring the existing `prefix_length_used` pattern exactly.

**Tech Stack:** Same as the base project — Next.js 14 App Router + TypeScript, Postgres via Drizzle ORM, Tailwind CSS, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-03-lupo-contagem-design.md` (updated 2026-09-04 with the optional-SKU and Produtos sections — read the whole spec, not just the diff, since this plan builds on the already-implemented base).

## Global Constraints

- `require_sku` is a global setting (key `require_sku` in the `settings` table, default `true`), frozen onto each `counting` row at creation time as `require_sku_used` — exactly like `prefix_length`/`prefix_length_used`. Changing the setting later never alters an in-progress or past counting.
- The `skus` table's new `name` column is **nullable** — a SKU linked inline while scanning (the existing flow) still only captures a SKU string, no name; only the Produtos screen captures a name. Never make `name` required at the DB level.
- The `require_sku_used` column MUST have a DB-level default of `true` (`.notNull().default(true)`) — dozens of existing tests insert `countings` rows directly without specifying this column, and giving it a default means none of that pre-existing test fixture code needs to change.
- When `require_sku_used` is `false` and a scanned barcode has no linked SKU and none was provided, the scan is **still recorded** (unlike the mandatory case, which throws `SkuRequiredError` and writes nothing) — `BoxHit.sku` and each `skuBreakdown` entry's `sku` become `string | null`, with `null` displayed as "Sem SKU" everywhere (box list, CSV export, WhatsApp text) — the same visual treatment as an unnamed group.
- Because a scan can now legitimately have no matching `skus` row, `GET /api/countings/:id`'s per-box SKU breakdown query changes from `JOIN` to `LEFT JOIN` — a box's total must still equal the sum of its breakdown entries (including the "Sem SKU" one), never lose scans.
- Every spoken announcement still says the box **number** only — this plan does not touch `hooks/useSpeechAnnouncer.ts` or that constraint in any way.
- Products are keyed by exact `barcode` (same table/key as the existing SKU link), so creating a product with a barcode that already exists is rejected (409) — editing goes through `PUT`, not a second `POST`.
- The CSV import format is fixed: semicolon-delimited, header row required with columns `nome`, `sku`, `codebar` in any order (matched case-insensitively by name, not position). Importing a barcode that already exists **overwrites** its `sku` and `name`. Invalid rows (bad barcode, blank sku, blank name) are skipped and reported by line number — they never abort the rest of the import. A file missing the required header columns is rejected before any row is processed.

```ts
import { eq } from 'drizzle-orm';
import { settings } from '@/db/schema';
import type { DbClient } from '@/db/client';

export const REQUIRE_SKU_KEY = 'require_sku';
export const DEFAULT_REQUIRE_SKU = true;

export async function getRequireSku(db: DbClient): Promise<boolean> {
  const row = await db.select().from(settings).where(eq(settings.key, REQUIRE_SKU_KEY)).limit(1);
  if (!row[0]) return DEFAULT_REQUIRE_SKU;
  return row[0].value === 'true';
}
```

```ts
import { NextResponse } from 'next/server';
import { db } from '@/db/client';
import { settings } from '@/db/schema';
import { PREFIX_LENGTH_KEY, getPrefixLength } from '@/lib/getPrefixLength';
import { REQUIRE_SKU_KEY, getRequireSku } from '@/lib/getRequireSku';

export const dynamic = 'force-dynamic';

export async function GET() {
  const prefixLength = await getPrefixLength(db);
  const requireSku = await getRequireSku(db);
  return NextResponse.json({ prefixLength, requireSku });
}

export async function PUT(req: Request) {
  let body: any;
  try {
    body = await req.json();
  } catch {
    return NextResponse.json({ error: 'invalid_json' }, { status: 400 });
  }
  const prefixLength = Number(body.prefixLength);
  if (!Number.isInteger(prefixLength) || prefixLength < 1 || prefixLength > 20) {
    return NextResponse.json({ error: 'invalid_prefix_length' }, { status: 400 });
  }
  if (typeof body.requireSku !== 'boolean') {
    return NextResponse.json({ error: 'invalid_require_sku' }, { status: 400 });
  }
  await db
    .insert(settings)
    .values({ key: PREFIX_LENGTH_KEY, value: String(prefixLength) })
    .onConflictDoUpdate({ target: settings.key, set: { value: String(prefixLength) } });
  await db
    .insert(settings)
    .values({ key: REQUIRE_SKU_KEY, value: String(body.requireSku) })
    .onConflictDoUpdate({ target: settings.key, set: { value: String(body.requireSku) } });
  return NextResponse.json({ prefixLength, requireSku: body.requireSku });
}
```

```ts
import { NextResponse } from 'next/server';
import { asc } from 'drizzle-orm';
import { db } from '@/db/client';
import { skus } from '@/db/schema';

export const dynamic = 'force-dynamic';

export async function GET() {
  const rows = await db.select().from(skus).orderBy(asc(skus.barcode));
  return NextResponse.json({ products: rows });
}

export async function POST(req: Request) {
  let body: any;
  try {
    body = await req.json();
  } catch {
    return NextResponse.json({ error: 'invalid_json' }, { status: 400 });
  }
  const barcode = String(body.barcode ?? '').trim();
  const sku = String(body.sku ?? '').trim();
  const name = String(body.name ?? '').trim();
  if (!barcode || !sku || !name) {
    return NextResponse.json({ error: 'invalid_product' }, { status: 400 });
  }
  try {
    const [row] = await db.insert(skus).values({ barcode, sku, name }).returning();
    return NextResponse.json({ product: row }, { status: 201 });
  } catch (err: any) {
    if (err.code === '23505') {
      return NextResponse.json({ error: 'barcode_already_registered' }, { status: 409 });
    }
    throw err;
  }
}
```

```ts
import { eq } from 'drizzle-orm';
import { db } from '@/db/client';
import { skus } from '@/db/schema';

export const dynamic = 'force-dynamic';

export async function PUT(req: Request, { params }: { params: { barcode: string } }) {
  let body: any;
  try {
    body = await req.json();
  } catch {
    return NextResponse.json({ error: 'invalid_json' }, { status: 400 });
  }
  const sku = String(body.sku ?? '').trim();
  const name = String(body.name ?? '').trim();
  if (!sku || !name) {
    return NextResponse.json({ error: 'invalid_product' }, { status: 400 });
  }
  const [row] = await db.update(skus).set({ sku, name }).where(eq(skus.barcode, params.barcode)).returning();
  if (!row) {
    return NextResponse.json({ error: 'not_found' }, { status: 404 });
  }
  return NextResponse.json({ product: row });
}

export async function DELETE(_req: Request, { params }: { params: { barcode: string } }) {
  const [row] = await db.delete(skus).where(eq(skus.barcode, params.barcode)).returning();
  if (!row) {
    return NextResponse.json({ error: 'not_found' }, { status: 404 });
  }
  return NextResponse.json({ ok: true });
}
```

```ts
export class InvalidCsvHeaderError extends Error {}

export interface ParsedProductRow {
  barcode: string;
  sku: string;
  name: string;
}

export interface ProductRowError {
  line: number;
  reason: string;
}

export interface ParseProductsCsvResult {
  rows: ParsedProductRow[];
  errors: ProductRowError[];
}

export function parseProductsCsv(csv: string): ParseProductsCsvResult {
  const lines = csv.split(/\r?\n/).filter((line) => line.trim().length > 0);
  if (lines.length === 0) throw new InvalidCsvHeaderError();

  const header = lines[0].split(';').map((h) => h.trim().toLowerCase());
  const nameIdx = header.indexOf('nome');
  const skuIdx = header.indexOf('sku');
  const barcodeIdx = header.indexOf('codebar');
  if (nameIdx === -1 || skuIdx === -1 || barcodeIdx === -1) throw new InvalidCsvHeaderError();

  const rows: ParsedProductRow[] = [];
  const errors: ProductRowError[] = [];

  for (let i = 1; i < lines.length; i++) {
    const cols = lines[i].split(';');
    const barcode = (cols[barcodeIdx] ?? '').trim();
    const sku = (cols[skuIdx] ?? '').trim();
    const name = (cols[nameIdx] ?? '').trim();
    const line = i + 1;

    if (!name) {
      errors.push({ line, reason: 'nome em branco' });
      continue;
    }
    if (!sku) {
      errors.push({ line, reason: 'SKU em branco' });
      continue;
    }
    if (!/^\d+$/.test(barcode)) {
      errors.push({ line, reason: 'código de barras vazio ou não numérico' });
      continue;
    }
    rows.push({ barcode, sku, name });
  }

  return { rows, errors };
}
```

```ts
import { NextResponse } from 'next/server';
import { eq } from 'drizzle-orm';
import { db } from '@/db/client';
import { skus } from '@/db/schema';
import { InvalidCsvHeaderError, parseProductsCsv } from '@/lib/parseProductsCsv';

export const dynamic = 'force-dynamic';

export async function POST(req: Request) {
  let body: any;
  try {
    body = await req.json();
  } catch {
    return NextResponse.json({ error: 'invalid_json' }, { status: 400 });
  }
  const csv = typeof body.csv === 'string' ? body.csv : '';

  let parsed;
  try {
    parsed = parseProductsCsv(csv);
  } catch (err) {
    if (err instanceof InvalidCsvHeaderError) {
      return NextResponse.json({ error: 'invalid_csv_header' }, { status: 400 });
    }
    throw err;
  }

  let created = 0;
  let updated = 0;
  for (const row of parsed.rows) {
    const existing = await db.select().from(skus).where(eq(skus.barcode, row.barcode)).limit(1);
    if (existing[0]) {
      await db.update(skus).set({ sku: row.sku, name: row.name }).where(eq(skus.barcode, row.barcode));
      updated++;
    } else {
      await db.insert(skus).values({ barcode: row.barcode, sku: row.sku, name: row.name });
      created++;
    }
  }

  return NextResponse.json({ created, updated, errors: parsed.errors });
}
```
